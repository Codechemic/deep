## 1. 접근 방법 (1쪽 이내)

어떤 딥러닝 모델을 어떤 데이터로 어떻게 학습시켰고, 학습된 모델을 탐색에 어떻게 결합했는지 쓴다.
기본 코드에서 바꾼 부분과 그 이유를 명확히 표시한다. 기본 코드와 같은 부분은 "그대로"라고 적는다.

## 2. 실험 설정

- 학습 데이터 생성 방식과 규모
- 모델 구조, 하이퍼파라미터
- 학습 환경(Colab GPU 종류 등)과 소요 시간

## 3. 결과

`python -m cube.evaluate --problems data/public_problems.json` 출력표를 붙인다.

## 4. 애블레이션 (필수, 최소 1개)

한 가지 요소를 바꿨을 때 결과가 어떻게 달라졌는지 표로 보인다. 첫 행은 **기본 코드 그대로**의 결과여야 한다.
예: 탐색 방식, 학습 샘플 수, 최대 섞기 깊이, 모델 크기, 라벨 생성 방식.

## 5. 실패 분석 (필수)

못 푼 문제들의 공통점은 무엇인가. 모델 예측값과 실제 남은 거리가 어긋나는 사례를 하나 이상 분석한다.

## 6. 참고 자료와 외부 코드 사용 내역
